# Pollen-based reconstruction using Machine Learning methods

This repository contains the code used in the manuscript on pollen reconstruction of vegetation type and mean annual temperature (MAT) using machine learning methods.

## Data Availability

The modern pollen data used in this study were derived from the modern pollen dataset of China compiled by Chen et al. (2021). Climatic variables were extracted from WorldClim (Fick and Hijmans, 2007), and vegetation-type information was assigned based on Zhang et al.(2007). These data were then merged and processed to generate the training and testing datasets used for model development and evaluation.

Since no explicit copyright statement or data redistribution terms were found on the journal website, the modified data files are not shared in this repository. The processed training and testing datasets can be obtained from Tinglu Yang upon reasonable request for the purpose of reproducing the results reported in the manuscript.

This repository includes the scripts used for data processing, model training, and basic visualization. The scripts were written in Python and R. Please note that the final figures presented in the manuscript were further refined using Apple Numbers and vector graphics software.
